How it works

SCAN

Find what's outdated

Checks Homebrew, Cask, the Mac App Store, and app update feeds.

UPDATE

One-click upgrades

Install updates in one click. App Store items open the App Store's Updates page.

ADOPT

Never update by hand

Move hand-installed apps under Homebrew, so they update with everything else.
